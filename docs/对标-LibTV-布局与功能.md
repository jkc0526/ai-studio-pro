### 创作起点
- **新建画布创作**（主入口，卡片最大）
- 模板/作品「查看创作过程」—— 每个社区作品都能回看创作过程，这是很聪明的获客与教学设计

### 作品广场（TV Show）
分类：全部 · 一场戏的诞生 · 无畏契约觉醒计划 · 精选画布 · 专业影视 · 短剧漫剧 · 商业广告 · 动漫游戏 · 教育生活 · TV工具箱
每张卡：作品名 + 作者 + 播放/点赞数 + 「查看创作过程」

### LibTV Agent（本次最有参考价值的部分）
- 一个兜底输入框：**「说出你的创意，或者从一个 skill 开始创作」**
- Skill chips 直接列在输入框下方：`POP MV 音乐MV` · `是枝裕和电影美学 专业影视` · `真人感美妆UGC 商业广告`
- 右侧「查看全部 skills」→ 存在 Skill 目录（本次点击时页面 A/B 版本没渲染出该按钮，未取到完整清单）
- 交互暗示：Agent 不是「聊天窗口」，而是**一句话 → 选 Skill → 直接产出成片**，Skill 是封装好的创作套路

## 五、与 WeaveCanvas 的对照

| 维度 | LibTV | WeaveCanvas 现状 | 建议 |
| --- | --- | --- | --- |
| 外壳结构 | 左侧栏 + 顶栏 + 内容区，工作台复用同一外壳 | 完全一致（同结构） | ✅ 已对齐 |
| 左侧栏 | 68px 折叠 / 192px 展开，图标态 | 208px 常驻文字 | 可考虑折叠态省空间（低优先） |
| 创作起点 | 「新建画布创作」大卡 + 能力卡网格 | 创作台一句话输入 + 6 快捷入口 | ✅ 已对齐 |
| Agent 定位 | 导航第二项，一句话 + Skill 直出 | 「Agent 应用」在导航第 7 位，岗位化编排 | **建议前置到导航靠前位置** |
| Skill 机制 | 预设创作套路（POP MV / 某导演风格 / 某品类广告），一键套用 | 有「提示词片段库」+ 岗位人设，但没有**成套 Skill** 概念 | **建议做 Skill 包：风格+提示词链+参数+步骤模板** |
| 作品回看 | 每个社区作品可「查看创作过程」 | 有运行时间线（agent_step），但只在运行时可见 | 建议做成**可分享的运行报告**（P3 已规划） |
| 特色工具 | 导演台(3D) / 逐帧拉片 / 片段重拍 / 口播 | 有 3D导演台节点、片段重拍（=分镜重做） | 逐帧拉片、口播视频可作候选 |
| 作品广场 | 有，带分类与社区数据 | 无（本地工具） | 不建议做（本地隐私定位，不必社交化） |
| 计费 | 积分 + 会员 | 不涉及（用户自带 Key） | 不适用 |

## 六、结论：值得抄的三件事（按性价比排序）

1. **Skill 成套化**：把「风格 + 提示词 + 参数 + 步骤」打成一个 Skill 包，Agent 输入框下方直接列 chips 一键套用。
   我们已有全部零件（风格库、片段库、Agent 岗位、流水线工具），只是没打包。**这是投入产出比最高的一项。**
2. **Agent 入口前置**：LibTV 把 Agent 放在导航第二项。我们的「Agent 应用」排在 7 位，建议上移到「创作台」下方。
3. **创作过程可回看/可分享**：我们的 `agent_step` 已经逐步落库，把它渲染成一份可导出、可分享的「创作过程报告」，比社区广场更符合本地工具的定位。

不建议抄的：作品广场/社区、积分会员体系（我们是本地自带 Key 的工具）。
