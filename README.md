# WeaveCanvas · AI 漫剧创作流水线

对标 LibTV（无限画布 + 节点工作流）与 OiiOii（多 Agent 数字剧组）的本地实现：**一句话 → 剧本 → 分镜 → 角色一致性 → 批量出图 → 图生视频 → 成片导出**，数据全在本机，支持任意 OpenAI 兼容网关与自定义 REST 接口。

## 快速开始

```bash
cd "E:\work Buddy\weave-canvas"
npm install                 # 已安装可跳过
npm run dev                 # 开发：前端 5173 + 后端 8787
```

**创作台**：输入一句话（或粘贴小说），选风格与镜头数，点「开始创作」→ 自动建剧本、写正文、拆分镜并跳到分镜页。

## 生产流水线

**① 剧本** → `① 一键拆分镜`（可覆盖或追加，覆盖前会确认删除数量）/ `② 从剧本提取角色`
**② 分镜** → `⚡ 批量生图` / `🎞 批量视频` / `🎬 导出成片`（并发 2 队列 + 实时进度）
**③ 角色** → 形象锁定档案 + `生成三视图`
**④ 画布** → 自由节点创作（文本/大模型/生图/备注 + 连线执行）

### 一致性是怎么做到的

每镜提示词按固定顺序拼装（`server/pipeline.js`）：

```
[风格前缀] + [镜头画面描述] + [角色形象保持一致：角色档案的 外貌 + 服装] + [镜头语言] + [画质约束]
```

角色档案一旦确定，所有镜头共用同一段形象描述 → 跨镜头不崩脸；风格由风格库统一注入 → 不跳戏。

### 成片导出

`🎬 导出成片` 用 ffmpeg 按镜序拼接竖屏 MP4（1080×1920 / 30fps / faststart）+ 同名 **SRT 字幕**，自动跳过没有素材的镜头并回报镜号。
ffmpeg 查找顺序：`WEAVE_FFMPEG` → `data/runtime/ffmpeg/` → `ffmpeg-static` → 本机其他软件自带 → PATH（`GET /api/ffmpeg` 可查）。

## 模型与接口

### 三类用途，各自独立配置

| 用途 | 走什么接口 | 默认 |
| --- | --- | --- |
| 文本模型 | `/chat/completions`、`/messages`(Anthropic)、`generateContent`(Gemini) | agnes-2.5-flash |
| 图像模型 | `/images/generations` | agnes-image-2.1-flash |
| 视频模型 | `/video/generations` + 轮询 `/videos/{id}` | agnes-video-v2.0 |

每个用途的**来源**三选一，优先级：**自定义接口 > 供应商 > 直填地址**。

### 内置 12 个供应商预设

OpenAI 官方 · Anthropic Claude · Google Gemini · 硅基流动 · 阿里云百炼 · 火山方舟 · DeepSeek · 月之暗面 Kimi · 智谱 GLM · OpenRouter · 本地 Ollama · 自建中转站（选中后只需填 Key）。

### 自定义 API 接口（可接任何 REST）

在「设置 → 自定义接口」里填：

| 字段 | 说明 |
| --- | --- |
| URL 模板 | `https://api.x.com/v1/xxx` 或 `{{base_url}}/xxx` |
| 请求体模板 | JSON 文本，占位符：`{{prompt}} {{image}} {{model}} {{size}} {{duration}} {{system}} {{user}} {{max_tokens}} {{base_url}} {{api_key}}` |
| 结果字段路径 | 如 `data.0.url` / `data.0.b64_json` / `choices.0.message.content`（留空则自动识别） |
| 轮询（可选） | 轮询 URL（用 `{{id}}`）、间隔、最大次数、状态字段路径、完成/失败值、结果字段路径 |

「试跑」会真实发一次请求并回显请求 URL、耗时、取到的结果与响应摘要。

### 模型可用性实测（不消耗额度）

用「故意缺少必填参数」的请求探测：能访问会返回 `prompt is required`，无权限返回 403 / `model_not_found`。
设置页点「检测可用性」即可标注 ✓ / ⏳限流 / ✕，**不要**相信网关 403 里的 `models=[...]` 白名单——它按端点给出，与视频、图像接口的实际权限并不一致（实测踩过这个坑）。

## 已知限制

- 批量任务为并发 2 的队列，运行中不可取消。
- **免费额度限流**：短时间连续调用会返回 429，服务端自动退避重试（8s/20s/40s）；批量视频建议错峰。
- 成片导出统一去音轨（画面 + SRT 字幕），保留原声待后续版本。
- 拆分镜依赖模型输出 JSON，若被长度上限截断会自动保留完整镜头并提示，可减少镜头数重试。

## 生产流水线（顶部四个视图）

**① 剧本** — 写或粘贴小说原文，选好「风格」，然后：
- `① 一键拆分镜`：AI 输出结构化镜头表（画面描述 / 台词 / 镜头语言 / 时长 / 出镜角色），自动关联角色档案
  - 可选 **覆盖已有镜头**（默认，先确认再删）或 **追加到现有镜头**（追加后自动重排序号，不会出现重复镜号）
- `② 从剧本提取角色`：AI 生成**形象锁定档案**（性别年龄、发型五官、体型、识别特征、常驻服装）

**② 分镜** — 多宫格分镜工作台（2/3/4 列切换）：
- `⚡ 批量生图` / `🎞 批量视频` / `🎬 导出成片`：队列并发 2，顶部实时进度条（成功/失败/百分比）
- `每镜 N 版`：一次生成 1/2/4 个版本，卡片下方出现版本条，点任意缩略图即采用该版为定稿
- 单镜操作：重生成图、图生视频（自动带上一镜的画面描述与镜头语言）、改描述/台词、增删出镜角色、看提示词
- 空镜自动跳过：导出时会列出被跳过的镜号，不会因为个别镜头没图而整体失败

**③ 角色** — 角色卡管理 + `生成三视图`（正面/侧面/背面设定稿），用于锁定形象

**④ 画布** — 自由节点画布（文本/大模型/生图/备注 + 连线执行），用于手工精调

### 成片导出

`🎬 导出成片` 会用 ffmpeg 把镜头按序拼接成竖屏 MP4（1080×1920 / 30fps），并生成同名 **SRT 字幕**（按镜序与时长对齐台词）。
ffmpeg 的查找顺序：`WEAVE_FFMPEG` 环境变量 → `data/runtime/ffmpeg/` → `ffmpeg-static` → 本机其他软件自带的 ffmpeg → PATH。
可用 `GET /api/ffmpeg` 查看当前实际使用的路径。

### 模型权限自愈

网关会返回 `This team can only access models=[...]`，服务端会解析并缓存到 `kv.model_acl`，
`/api/models` 据此把模型分成「可选 / 受限」两组，前端下拉只列可用的，并按文本/图像/视频自动给出默认值。

### 视频接口（已实测）

```
POST {base}/video/generations   {model, prompt, image, duration}  → {task_id, status:"queued"}
GET  {base}/videos/{task_id}    → status: queued|completed, progress, url
```
服务端自动轮询（5 秒一次、最长 10 分钟）、下载到 `data/outputs/`、登记到 `media_asset`；
命中 429 限流时按 8s/20s/40s 退避重试 3 次。实测单镜出片约 100–160 秒（`agnes-video-v2.0`，5 秒 1088×832 24fps）。

## 常见问题

**Q：点了保存，重开设置输入框还是空的 —— 是没存上吗？**
A：已存密钥不会明文回显（安全考虑）。请看 API Key 右侧标签：显示 `已保存 sk-xxx••••1234` 即为已生效，对应 tab 上也会出现绿点。想确认是否真能用，点「测试连接」。

**Q：运行节点报「API Key 为空」？**
A：该 purpose 的密钥没存上，或被「清除」了。到设置里对应 tab 看标签状态。

**Q：报「无法连接到服务器」？**
A：`Base URL` 与密钥必须属于同一服务商。例如 agnes 的密钥要配 `https://apihub.agnes-ai.com/v1`；配 `https://api.openai.com/v1` 连不通（国内访问 openai 通常也需要代理）。
