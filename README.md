# WeaveCanvas · AI 漫剧创作流水线

对标 LibTV（无限画布 + 节点工作流）与 OiiOii（7 Agent 数字剧组）的本地实现：**剧本 → 分镜 → 角色一致性 → 批量出图 → 成片**，全部数据在本机，自带 API Key。

## 快速开始

```bash
cd weave-canvas
npm install                 # 已安装可跳过
npm run dev                 # 前端 http://127.0.0.1:5173（后端自动起在 8787）

# 生产模式
npm run build
npm start                   # 直接访问 http://127.0.0.1:8787
```

## 生产流水线（顶部四个视图）

**① 剧本** — 写或粘贴小说原文，选好「风格」，然后：
- `① 一键拆分镜`：AI 输出结构化镜头表（画面描述 / 台词 / 镜头语言 / 时长 / 出镜角色），自动关联角色档案
  - 可选 **覆盖已有镜头**（默认，先确认再删）或 **追加到现有镜头**（追加后自动重排序号，不会出现重复镜号）
- `② 从剧本提取角色`：AI 生成**形象锁定档案**（性别年龄、发型五官、体型、识别特征、常驻服装）

**② 分镜** — 多宫格分镜工作台（2/3/4 列切换）：
- `⚡ 批量生图` / `🎞 批量视频` / `🎬 导出成片`：队列并发 2，顶部实时进度条（成功/失败/百分比）
- `每镜 N 版`：一次生成 1/2/4 个版本，卡片下方出现版本条，点任意缩略图即采用该版为定稿
- 单镜操作：重生成图、图生视频（自动带上一镜的画面描述与镜头语言）、改描述/台词、增删出镜角色、看提示词
- 空镜自动跳过：导出时会列出被跳过的镜号，不会因为个别镜头没图而整体失败

**③ 角色** — 角色卡管理 + `生成三视图`（正面/侧面/背面设定稿），用于锁定形象

**④ 画布** — 自由节点画布（文本/大模型/生图/备注 + 连线执行），用于手工精调

### 成片导出

`🎬 导出成片` 会用 ffmpeg 把镜头按序拼接成竖屏 MP4（1080×1920 / 30fps），并生成同名 **SRT 字幕**（按镜序与时长对齐台词）。
ffmpeg 的查找顺序：`WEAVE_FFMPEG` 环境变量 → `data/runtime/ffmpeg/` → `ffmpeg-static` → 本机其他软件自带的 ffmpeg → PATH。
可用 `GET /api/ffmpeg` 查看当前实际使用的路径。

### 模型权限自愈

网关会返回 `This team can only access models=[...]`，服务端会解析并缓存到 `kv.model_acl`，
`/api/models` 据此把模型分成「可选 / 受限」两组，前端下拉只列可用的，并按文本/图像/视频自动给出默认值。

### 视频接口（已实测）

```
POST {base}/video/generations   {model, prompt, image, duration}  → {task_id, status:"queued"}
GET  {base}/videos/{task_id}    → status: queued|completed, progress, url
```
服务端自动轮询（5 秒一次、最长 10 分钟）、下载到 `data/outputs/`、登记到 `media_asset`；
命中 429 限流时按 8s/20s/40s 退避重试 3 次。实测单镜出片约 100–160 秒（`agnes-video-v2.0`，5 秒 1088×832 24fps）。

### 一致性是怎么做到的

每一镜的提示词按固定顺序拼装（`server/pipeline.js`）：

```
[风格前缀] + [镜头画面描述] + [角色形象保持一致：角色档案的 外貌 + 服装] + [镜头语言] + [画质约束]
```

角色档案一旦确定，所有镜头共用同一段形象描述，因此跨镜头不崩脸；风格由风格库统一注入，因此不跳戏。

## 接口一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/scripts/:id/split` | 剧本 → 镜头表（容错解析被截断的 JSON） |
| POST | `/api/scripts/:id/extract-characters` | 剧本 → 角色档案 |
| POST | `/api/shots/:id/image` | 单镜生图 |
| POST | `/api/scripts/:id/images` | 批量生图，返回 jobId |
| GET | `/api/jobs/:id` | 批量任务进度 |
| POST | `/api/characters/:id/sheet` | 角色三视图 |
| GET | `/api/models` | 代理网关模型列表（供下拉选择） |

```
│  ├─ App.jsx      壳：视图切换 + 全局状态
│  ├─ views/       ScriptView / StoryboardView / CharactersView / CanvasView
│  ├─ nodes/       画布四类自定义节点
│  └─ components/  设置弹窗、片段库面板
└─ data/           weave.db + outputs/（运行时生成）
```

## 与 LibTV / OiiOii 还有差距的地方

| 能力 | 现状 |
| --- | --- |
| 配音/BGM | ❌ 网关只有文本/图像/视频三类模型，**没有 TTS/音乐模型**；目前成片为无声 + 字幕版 |
| 角色一致性 | ⚠️ 靠提示词注入锁定（实测跨镜稳定）；尚未用参考图 image-to-image 二次锁定 |
| 图像工具箱 | ❌ 无放大/扩图/抠图/重绘/多角度/打光预设 |
| 多宫格连贯分镜 | ⚠️ 有 2/3/4 列宫格与批量出图，无 9/25 宫格一次成图 |
| 工作流复用 | ❌ 无打组保存、模板市场 |
| 对话式精调 | ❌ 尚无「跟导演助理说话改片」 |
| 桌面端 | ❌ 未打包 exe |

## 已知限制

- 工作流与批量任务为串行/并发 2 的队列，运行中不可取消。
- **免费额度限流**：同一账号短时间连续调用会返回 429，服务端自动退避重试；批量视频建议错峰跑。
- 成片导出目前统一去音轨（图片镜无声、视频镜也静音），只输出画面 + SRT；保留原声待阶段三。
- 分镜拆分镜依赖模型输出 JSON，若被长度上限截断会自动保留完整镜头（提示 warning），可减少镜头数重试。
- 未打包桌面端；如需 exe，可在此结构上直接套 Tauri。

## 常见问题

**Q：点了保存，重开设置输入框还是空的 —— 是没存上吗？**
A：已存密钥不会明文回显（安全考虑）。请看 API Key 右侧标签：显示 `已保存 sk-xxx••••1234` 即为已生效，对应 tab 上也会出现绿点。想确认是否真能用，点「测试连接」。

**Q：运行节点报「API Key 为空」？**
A：该 purpose 的密钥没存上，或被「清除」了。到设置里对应 tab 看标签状态。

**Q：报「无法连接到服务器」？**
A：`Base URL` 与密钥必须属于同一服务商。例如 agnes 的密钥要配 `https://apihub.agnes-ai.com/v1`；配 `https://api.openai.com/v1` 连不通（国内访问 openai 通常也需要代理）。

## 本地数据

- `data/weave.db`：画布、配置、片段、执行日志（密钥明文存于此，仅本机）
- `data/outputs/`：生成的图片
- `data/weave.db-wal.backup`：一次性恢复备份，确认配置无误后可删除
